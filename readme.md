# Smart Healthcare Data Management Using Cloud Computing

🌐 **Live Deployed Application:** [Click Here to Open Live App](https://smart-healthcare-cloud-jgwtettkpca7kvnbhuecka.streamlit.app/)

A cloud-based healthcare web application developed using **Python (Streamlit)** and **Supabase Cloud (PostgreSQL Database & Object Storage)**.

## Key Modules
1. **Patient Data Management & Cloud Storage:** Register patient details and securely upload medical reports/scans directly to cloud storage.
2. **Cloud Patient Records:** Search, filter, and download patient records and attached reports in real time.
3. **Healthcare Data Analytics & Report Generation:** Interactive visual analytics dashboard and automated official PDF medical report generation.

## Tech Stack
* **Frontend & Backend:** Python, Streamlit
* **Cloud Database & Storage:** Supabase (PostgreSQL + Cloud Storage Bucket)
* **Analytics & Reporting:** Pandas, Plotly, FPDF
